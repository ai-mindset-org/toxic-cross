# Свой источник

Источник – это файл-адаптер в `адаптеры/`, который читает что-то своё и превращает это в блоки на кресте. Три живых примера в репозитории: календарь из ICS, задачи из JSON-выгрузки, отклики на кнопки ритуала. Шаблон для нового источника – `адаптеры/ОБРАЗЕЦ.py`, скопировать и переименовать.

## Контракт

Функция с одной сигнатурой:

```python
def собрать(правила, сейчас):
    ...
    return {"статус": ..., "элементы": [...], "события": [...], "заметка": "..."}
```

`правила` – уже разобранный `правила.json`, свой раздел лежит по пути `правила["источники"]["<имя>"]`. `сейчас` – `datetime` с часовым поясом, точка отсчёта времени для всех расчётов. Возврат: `статус` источника, список `элементы` (блоки на крест), список `события` для ленты дня (можно пустой), строка `заметка` для строки источников на поле.

## Поля элемента

| поле | смысл |
|---|---|
| `id` | устойчивый идентификатор между сборками; по нему ручные наложения находят элемент |
| `т` | короткая подпись, видна на луче |
| `луч` | один из: обязательства, будущее, ресурсы, прошлое |
| `вес` | базовое число до масштаба источника и затухания по времени |
| `т_ч` | часы от сейчас: вперёд плюс, назад минус |
| `охват` | ситуативное, недельное или глобальное – см. [механика](механика.md) |
| `источник` | ключ в `правила.json["источники"]`, по нему берётся масштаб |
| `факт` | чем обоснован вес: число, срок, счётчик – без факта блок ничего не объясняет |
| `флип` | что с этим можно сделать – см. [переворот](переворот.md) |
| `природа` | `тянет` вверх или `держит` внизу, отдельно от луча |
| `знак` | `+` помечает элемент опорой – так закрытая задача остаётся на луче прошлого, но природа у неё держит |
| `срочно` | `true` сажает блок в центр луча – просрочено или идёт прямо сейчас |

## Четыре статуса плюс образец

- `live` – данные есть, источник работает штатно.
- `quiet` – источник доступен, но пуст, и это норма (у отклика – пока не было ни одного клика).
- `dead` – источник недоступен, поймано исключение; в заметке короткая причина.
- `off` – источник выключен флагом `--без` при запуске сборки, или не описан в `правила.json`.

Отдельно есть демонстрационный режим (в адаптере календаря – статус `образец`): без настройки окружения адаптер читает встроенный файл-образец и переносит его даты на сегодня, чтобы поле было живым сразу после клонирования репозитория. На экране в этом случае выдуманный день, и статус явно на это указывает.

## Пять правил приличия

Из `ОБРАЗЕЦ.py`, проверены на трёх живых источниках:

1. **Падать тихо.** Источник недоступен – вернуть `dead` с короткой заметкой, не бросать исключение наружу. Поле нарисует остальные три луча и покрасит этот источник красным; одна поломка не должна гасить весь крест.
2. **Не ходить дважды.** Дорогой источник читается по снимку на диске: адаптер кэширует чтение сам, решение о повторном походе к источнику не отдаётся расписанию сборки снаружи.
3. **Сворачивать хвост.** Поимённо на крест приходит только горящее – просроченное, срочное, тяжёлое. Остальное складывается в один блок со счётчиком («закрыто за месяц: 12»), иначе луч превращается в нечитаемый список из полусотни одинаковых точек.
4. **Отдавать факт и флип.** Факт объясняет число, флип называет действие. Без них блок молчит – он занимает место на кресте, но ничего не сообщает и ничего не предлагает сделать.
5. **Только чтение.** Адаптеру не нужны права на запись ни к одному источнику. Единственное исключение в самом инструменте – маршрут `/отклик` в `поле.py`, и он пишет в собственный файл репозитория `источники/отклики.json`.

## Как описать источник в правила.json

Раздел `правила["источники"]["<имя>"]` держит:

```json
"<имя>": {
  "луч": "обязательства",
  "охват": "недельное",
  "масштаб": 1.0,
  "правила": ["человеческое описание того, как считается вес"],
  "флип": "что можно сделать с этим блоком"
}
```

`масштаб` – множитель поверх базового веса, если источник в целом должен звучать тише или громче остальных. `правила` – список строк для читателя, не код: сборка их не парсит, они документируют то, что реализовано в адаптере.

## Как включить в сборку

Добавить имя файла (без `.py`) в список `АДАПТЕРЫ` в `собрать.py`:

```python
АДАПТЕРЫ = ['календарь_ics', 'задачи_json', 'отклики', '<имя>']
```

Порядок в списке не важен для расчёта, важен только для порядка попыток при сборке.

## Цена источника: с чего начинать

| уровень цены | пример | почему дороже |
|---|---|---|
| дёшево | локальный файл выгрузки (ICS, JSON) | чтение с диска, никакой сети и токенов, легко воспроизвести на любой машине |
| дороже | API живого трекера задач или календаря | сеть, авторизация, лимиты запросов, источник может быть недоступен именно тогда, когда особенно нужен |
| ещё дороже | счётчики переписки, скрапинг чатов | нужно решить, что считать (см. [безопасность](безопасность.md) – содержимое не должно попадать в собранный файл), выше риск случайно унести приватные данные в `день.json` |

Начинать стоит с файла выгрузки: он проверяет контракт адаптера без риска и без сетевых сбоев. API и счётчики переписки подключаются вторым и третьим шагом, когда контракт уже обкатан на дешёвом источнике.
