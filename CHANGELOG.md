# Changelog

## 2.0.0 – 2026-10-16 · experimental developer preview

- New English day workspace: event phases, readable balance, source receipts and a deliberate four-question method.
- Optional per-event feeling and energy check-ins, private local notes and browser export.
- Native quiet post-event reminders: off by default, generic body, one per day, no wake backlog.
- Calendar Control source selection and Spark's two-minute freshness window are respected.
- Optional explicit calendar sharing updates only the private board's calendar lane, without model calls or a new scheduler.
- Full native Swift source, build/tests/installer, browser workspace and a self-hosting API are included.
- Method documentation distinguishes source arithmetic, self-report and illustrative reframing.
- Distribution remains ad-hoc signed, Apple silicon, declared macOS 13+. Developer ID notarization and clean-machine macOS 13 testing remain outstanding.

Native local check-ins and browser-board check-ins are separate stores in this version. There is no automatic app updater or arbitrary executable plugin manager.
