# Changelog

## Workspace 2.2.0 – 2026-10-19

- Research fits smaller screens without a permanent detail column. A block opens in a side drawer; Escape restores focus to its control.
- Click a direction to inspect its records, relative weights and time horizons. Optional filters stay collapsed until needed.
- The private static index and all server entry aliases open the current workspace directly. The historical instrument remains an explicit archive.
- Check-in effects and the separate calendar/source-weight flow are explained in the interface and data-flow documentation.
- Mac download remains 2.1.0 build 11; this update changes the web workspace and source kit.

## 2.1.0 – 2026-10-19 · experimental developer preview

- Restored a wide research instrument: Cross, Time and Process views, complete four-direction records, search, filters and source details.
- The private board serves the current workspace directly; the preserved classic instrument is available under `/classic`.
- Shared check-ins between the private board and Mac companion, with offline retention, newest-edit conflict resolution and visible acknowledgement receipts.
- Source provenance separates manual annotations, canonical adapters, upstream captures and collection checks; original weight calculations and manual overrides are inspectable.
- Temporary per-record/per-direction/all-record previews keep the original normalization fixed and leave source records intact.
- Public demo, personal board and Mac companion boundaries are explained on the product/setup pages. Public examples never access personal sources.
- Existing native shell, local calendar source choices and quiet notification policy remain in place. Developer ID notarization remains outstanding.

## 2.0.0 – 2026-10-16 · experimental developer preview

- New English day workspace: event phases, readable balance, source receipts and a deliberate four-question method.
- Optional per-event feeling and energy check-ins, private local notes and browser export.
- Native quiet post-event reminders: off by default, generic body, one per day, no wake backlog.
- Calendar Control source selection and Spark's two-minute freshness window are respected.
- Optional explicit calendar sharing updates only the private board's calendar lane, without model calls or a new scheduler.
- Full native Swift source, build/tests/installer, browser workspace and a self-hosting API are included.
- Method documentation distinguishes source arithmetic, self-report and illustrative reframing.
- Distribution remains ad-hoc signed, Apple silicon, declared macOS 13+. Developer ID notarization and clean-machine macOS 13 testing remain outstanding.

Native local check-ins and browser-board check-ins are separate stores in this version. There is no automatic app updater or arbitrary executable plugin manager.
